# Changelog

This changelog summarizes the packaged changes. Git history is the source of truth for publication dates and revisions.

## Post-release update

- Removed the `<small>` wrapper from active-tag formatting instructions. The tag line remains separate, compact, regular-weight, and unbolded.

## Initial public release

- Added a full-catalog activation router and a method-trace requirement so relevant, less-used tags are less likely to be skipped and visible tags correspond to actual work.
- Added distinct icons for all 28 tags and a separate compact tag line with no heading, smaller regular-weight styling, and a divider before answer text.
- Added the Persian 28-tag operational protocol and updated the handoff and bilingual READMEs.
- Added English and Persian onboarding documentation.
- Added platform-specific installation guidance based on official client documentation.
- Added evaluation scenarios, a scoring rubric, security guidance, and contribution instructions.
- Added an explicit statement that no comparative performance benchmark has been run.
- Added copy-ready recipes for website-content review, app/site UX audits, and turning a finding into a verified change.
- Added explicit use cases and evaluation scenarios for content and UX reviews.
- Replaced the five-tag quota with a lightweight baseline and no upper limit; made active-tag display explicit; removed redundant planning jargon and added an explicit user-feedback-to-alternative workflow.
- Included the MIT license.
